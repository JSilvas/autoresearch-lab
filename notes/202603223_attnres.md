# 202603223_attnres

**Hypothesis**: Replace fixed per-layer resid_lambdas/x0_lambdas scalars with input-dependent softmax attention over all previous layer outputs (Attention Residuals, MoonshotAI 2026). Each layer gets a learned query vector w_l ∈ ℝ^d; h_l = Σ α_{i→l} · v_i where α are softmax-normalized. This generalizes x0_lambdas (content-independent x0 mixing) to full cross-layer attention — every layer can selectively draw from any predecessor based on current content. Paper claims 1.25x compute efficiency at scale. For depth=3: negligible overhead (3×256=768 extra params, O(Ld) extra memory).
**Target Metric**: val_bpb < 1.381845 (mar22 baseline)
**Code Change**: GPT.__init__ adds self.attn_res_queries (n_layer × n_embd learned query vectors). GPT.forward replaces `x = resid_lambdas[i]*x + x0_lambdas[i]*x0` with cross-layer softmax attention over history. Remove resid_lambdas and x0_lambdas parameters.
