# 2026031784_ns_steps5

**Hypothesis**: Muon uses Newton-Schulz orthogonalization with ns_steps=7 iterations. Fewer iterations (ns_steps=5) = slightly less accurate orthogonalization per step, but marginally faster iteration. With fixed TIME_BUDGET, fewer ns_steps might allow more gradient updates. The original Muon paper used 5 steps as default. Try MUON_NS_STEPS=5 — may recover performance with additional training steps.
