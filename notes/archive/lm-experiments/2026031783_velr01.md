**Hypothesis**: Value Embeddings (VE) currently use `EMBEDDING_LR=0.7` — same as token embeddings. But VE are structural: they inject value-biased information into each attention layer. Unlike token embeddings which need fast adaptation to learn per-token representations, VE are more like "architectural priors" that may benefit from a lower, more stable LR. Try VE_LR=0.1 — a 7x reduction relative to EMBEDDING_LR. Added VE_LR as dedicated parameter.
**Target Metric**: val_bpb < 1.369316
**Code Change**: Added VE_LR=0.1 hyperparameter; value_embeds now use VE_LR instead of EMBEDDING_LR
