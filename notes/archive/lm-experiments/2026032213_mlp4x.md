# MLP Width Expansion to 4x (Exp13)

## Overview
Increase the MLP expansion factor from 3x to 4x (i.e., the intermediate size is 4 * n_embd instead of 3 * n_embd) to increase model capacity without changing the number of layers.

## Changes Made
- In `train.py`, modify the MLP class to use 4 * config.n_embd for the intermediate layer:
  - Change `self.c_fc = nn.Linear(config.n_embd, 3 * config.n_embd, bias=False)` to `4 * config.n_embd`
  - Change `self.c_proj = nn.Linear(3 * config.n_embd, config.n_embd, bias=False)` to `nn.Linear(4 * config.n_embd, config.n_embd, bias=False)`
- Keep the same initialization scheme (using s = sqrt(3) * n_embd^{-0.5}) for simplicity; may revisit if unstable.

## Hypothesis
Increasing MLP width will increase the model's capacity to learn complex functions, potentially reducing val_bpb. However, with a fixed time budget, we must ensure that the increase in computation per step does not reduce the number of steps too much, which could hurt performance.

## Baseline
Current best: Activity-based LR scaling (Exp12) with val_bpb = 1.378481

## Next Steps
If this experiment improves val_bpb, consider trying 2x width or combining with other techniques (e.g., activity-based LR scaling). If it degrades, we may try 2x width to see if a narrower MLP works better.
