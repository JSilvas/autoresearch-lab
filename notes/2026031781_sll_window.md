# 2026031781_sll_window

**Hypothesis**: WINDOW_PATTERN="SSL" was confirmed at S=1024 (Exp20: SSL beat LSS, SL). But at S=64, S layers are nearly free (64-token window). The "SSL" pattern means layers 0,1 are both local. With S=64, each local layer only looks at 64 tokens before the global layer. Try "SLL" — only layer 0 is local, layers 1+2 are full global. Layer 0 local extraction still happens, but layer 1 gets full context earlier. May trade some local feature quality for richer intermediate representations.

With DEPTH=3 and `_compute_window_sizes` forcing last layer to L, "SLL" gives: [S=64, L=2048, L=2048(forced)] vs "SSL" → [S=64, S=64, L=2048(forced)].
