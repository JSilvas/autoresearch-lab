# 202603228_relu3

**Hypothesis**: ReLU³ (x³ for x>0, 0 for x≤0) is more sparse than ReLU² (sparser activations = more regularization, stronger specialization). Untested in mar17 — only ReLU² (best), GELU, ReLU were compared. ReLU³ has cubic growth for positive activations (larger gradient for large x, smaller relative gradient for medium x). With normalized MLP inputs (post-LayerNorm), activations ≈ unit scale, so the cubic vs quadratic difference is moderate.
**Target Metric**: val_bpb < 1.381845
**Code Change**: `x = F.relu(x).square()` → `x = F.relu(x).pow(3)` in MLP.forward
